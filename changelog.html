What's new

Every Quadrant release and what changed. Quadrant updates itself quietly, so you're probably already on the latest version.

    Latest Oct 26, 2026

    • NewAdded a Snap layouts section with an animation to the guide
  2. Oct 14, 2026

    Version 1.1.0

    Oct 14, 2026
    • Quadrant is now verified by Apple, so it opens without security warnings

    Oct 14, 2026

    Version 1.0.0

    Oct 13, 2026

    First public release of Quadrant.

    • Snap windows to halves, thirds, corners and other displays with one shortcut
    • Drag windows to screen edges to snap them
    • Move and resize windows from anywhere by holding ⌃⌥
    • Grid picker, tile all windows, saved layouts and app rules
    • Shortcut cheat sheet (⌃⌥⌘/)
    • Free, with quiet automatic updates
