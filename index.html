How to use Quadrant

Up and running in a minute. Everything lives in the menu bar icon.

1Get started

  1. Download Quadrant and drag it into your Applications folder.
  2. Open it. If macOS says it can't verify Quadrant, follow the three quick steps below. You only do this once.
  3. A setup window walks you through allowing Accessibility access, which macOS requires before any app can move windows.
  4. Click Open System Settings, turn Quadrant on, and come back. The setup window confirms when you're done.
  5. Look for the ▦ icon in your menu bar. That's Quadrant.

If macOS says it can't verify Quadrant

Quadrant is an independent app that isn't registered with Apple yet, so the first time you open it macOS shows a warning. It's safe to open. Here's how:

The exact wording varies a little between macOS versions. If you don't see the Open Anyway button, try opening Quadrant once more first. It only appears for about an hour after a blocked launch.

2Drag to snap

  1. Grab any window by its title bar.
  2. Drag your cursor all the way to a screen edge or corner.
  3. A blue preview shows where the window will go. Let go to snap it.

Changed your mind? Press ⌥⌘Z to undo. You can turn drag-to-snap off in Preferences → Mouse.

Seeing two previews? macOS has its own edge tiling. Turn off “Drag windows to screen edges to tile” in System Settings → Desktop & Dock.

3Save and restore layouts

  1. Arrange your windows the way you like them.
  2. Menu bar icon → Layouts → Save Current Layout… and give it a name, like “Coding”.
  3. Later, pick it from Layouts and every window jumps back into place.

In Preferences → Layouts you can give each layout its own shortcut, or turn on Auto-restore to apply it whenever the same monitors are connected, like when you dock your laptop.

4Turn Quadrant off in specific apps

  1. Switch to the app, for example your code editor.
  2. Click the menu bar icon and choose Disable Shortcuts in “App”.

That app's own shortcuts now work normally whenever it's in front. Manage the list in Preferences → Excluded Apps.

5Make the shortcuts yours

  1. Menu bar icon → Preferences… → Shortcuts.
  2. Click any field and press the keys you want. Esc cancels, Delete clears.

FAQ

Why does it need Accessibility access?

macOS only lets apps move other apps' windows after you allow them in System Settings → Privacy & Security → Accessibility. Quadrant uses that access only to position windows.

Does it work on Apple Silicon (M1–M5)?

Yes. Quadrant is a native universal app for Apple Silicon and Intel Macs on macOS 13 or later.

Is it really free?

Yes. Every feature, no trial, no account. Tips via Venmo or PayPal are appreciated but never required.

Dragging a window to the edge shows two previews.

That's macOS's built-in tiling running alongside Quadrant. Turn off “Drag windows to screen edges to tile” in System Settings → Desktop & Dock → Windows, or turn off Quadrant's version in Preferences → Mouse.

⌘← no longer jumps to the start of a line in my editor.

Quadrant uses ⌘← for Left Half by default. Exclude your editor (menu bar icon → Disable Shortcuts in “App”) or change the shortcut in Preferences → Shortcuts.

Will Quit App lose my unsaved work?

No. It quits apps the normal way, so they still ask you to save first. It never touches Finder or force-quits anything.

How does Auto-restore pick a layout?

Each layout remembers which monitors were connected when you saved it. When that exact set of monitors is connected again, Quadrant restores the layout marked Auto-restore.

Where are my layouts and settings stored? Does anything leave my Mac?

Nothing leaves your Mac. Your layouts, shortcuts and excluded apps are saved only on your computer, in Quadrant's preferences file. Quadrant has no account, no tracking and never connects to the internet. Layouts include window titles (like document names) so the right window can be restored; they stay private on your Mac. To erase everything, delete Quadrant and run defaults delete com.kouathao.quadrant in Terminal.

Holding ⌃⌥ and dragging clashes with another app.

Move & resize from anywhere uses ⌃⌥ by default. Pick different keys or turn it off in Preferences → Mouse. You can also add that app to Excluded Apps.

How do I use the grid picker?

Press ⌃⌥⌘G. A 6 × 4 grid covers the screen your window is on. Drag across the cells you want (or click one) and the window fills them. Press Esc to cancel.

Shortcuts stopped working.

Open System Settings → Privacy & Security → Accessibility, remove Quadrant with the − button, then add it back (or reopen Quadrant and follow the setup window).

How do I start it at login?

It's on by default. Toggle it from the menu bar icon or in Preferences.
